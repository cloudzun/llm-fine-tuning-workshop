# 第6章 安全、合规与模型治理

## 学习目标
1. 识别模型在现实应用中可能产生的风险（偏见、隐私泄露、滥用）；
2. 掌握常见的检测与缓解方法（内容过滤、差分隐私、脱敏）；
3. 理解合规要求与数据处理流程（隐私保护、许可管理）；
4. 能设计一个基本的模型治理流程并写成文档化 SOP。

---

## 1. 引言
在把模型投入生产前，工程团队必须评估与缓解潜在风险。本章结合工程实践，讨论如何在课程与项目中纳入安全与治理措施，使学员了解不仅要做技术实现，还要考虑合规与伦理。

---

## 2. 风险类型与示例
- 偏见（Bias）：训练数据偏倚导致的不公正输出；
- 隐私泄露：模型记忆训练数据中的敏感信息（PII）；
- 滥用风险：生成有害内容、诈骗等；
- 依赖性风险：过度信任模型输出导致的决策失误。

---

## 3. 检测与缓解方法
- 数据层面：去敏感化、合成替代、最小化数据保留；
- 模型层面：差分隐私训练、限制可生成内容的策略、对抗样本测试；
- 服务层面：内容过滤、速率限制、人工在环（human-in-the-loop）审批；

---

## 4. 练习（Exercises）
1. 设计一项实验以检测模型在特定子群上的偏差，并给出评估指标；
2. 对给定的数据集，提出脱敏策略并说明可能的残留风险；
3. 设计一个服务级别的安全策略（内容过滤 + logging + manual review）并给出实现步骤。
