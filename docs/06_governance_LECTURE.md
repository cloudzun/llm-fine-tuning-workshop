# 第6章 安全、合规与模型治理（教科书式）

## 学习目标
完成本章后，你应能：
1. 识别并分类模型在生产环境可能产生的风险；
2. 设计基本的检测与缓解策略（脱敏、过滤、差分隐私）；
3. 起草一份模型治理的 SOP 并在实验中应用至少一种缓解措施；
4. 理解合规文件与数据许可在工程流程中的位置与重要性。

---

## 1. 引言
模型治理不是法律合规的替代品，而是把合规与工程实践结合起来的流程化工作。本章提供检测与缓解的工程方法论，目标是让团队能在项目初期就嵌入治理考量，而不是在发布后再来补救。

---

## 2. 风险分类与检测方法
- 偏见检测：分群评估、差异化指标（不同子群的准确率/精确率等）；
- 隐私泄露检测：抽样生成检测、membership inference 测试；
- 滥用检测：模拟恶意 prompt 与过滤器评估；

---

## 3. Worked Example：偏见检测流程（设计）
示例：针对性别与职业关系做一个简单测试集，计算模型在不同子群上的回答倾向与质量差异，报告差异并给出缓解建议（数据增强、对齐数据、后处理过滤）。

---

## 4. 练习（Exercises）
1. 设计一个偏见检测实验并写出评价指标；
2. 对给定模型集成 Detoxify 做内容过滤并报告过滤效果；
3. 编写一份简短的模型治理 SOP（含谁负责、触发条件、缓解步骤）；
4. 讨论差分隐私训练在工程上的代价与适用场景。
