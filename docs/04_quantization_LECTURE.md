# 第4章 量化与推理优化（llama.cpp / GGUF / ONNX）

## 学习目标
1. 理解量化的必要性、基本策略与对模型精度的影响；
2. 掌握常用量化格式（INT8/INT4/GGUF）与工具链（llama.cpp、ONNX、GPTQ）；
3. 能设计基本的量化流程并评估质量—性能权衡。

---

## 1. 引言
在生产环境中，推理成本（延迟与资源）往往决定能否把模型投入真实业务。量化是把模型从高精度浮点表示转换为低比特表示以节省内存与提升吞吐的关键技术。本章从原理、格式、工具与工程实践角度系统讲解量化流程。

---

## 2. 量化基本概念
- 对称量化 vs 非对称量化；
- 逐层量化 vs per-channel 量化；
- 量化误差来源：截断误差、缩放因子选择、非线性激活的影响。

---

## 3. 常见格式与工具
- GGUF：llama.cpp 的现代模型格式，适配多种量化策略；
- ONNX/ONNXRuntime：跨框架的运行时与加速器支持；
- GPTQ / bitsandbytes：训练后量化与低比特格式支持工具。

---

## 4. 量化流程（工程化）
1. 选择校准数据（代表性小数据集）
2. 选择量化格式与策略（按硬件/目标性能）
3. 执行量化（工具链命令）并导出量化模型
4. 评估量化后模型（质量指标 + 性能指标）
5. 若需要，尝试量化感知微调或后处理校正
