# 第4章 量化与推理优化（教科书式）

## 学习目标
完成本章后，你应能：
1. 描述量化的基本原理、常见策略与误差来源；
2. 区分不同量化格式（INT8/INT4/GGUF）与适用场景；
3. 设计一个基础的量化流程并评估质量—性能权衡；
4. 运行并记录量化前后的基准指标。

---

## 1. 引言
量化通过降低数值表示的位宽，减少模型内存占用与计算带宽，从而提升推理效率。本章注重工程可操作性：如何选择量化策略、如何校准与评估以及常见的陷阱。

---

## 2. 量化核心概念
- 对称 / 非对称量化；
- per-tensor / per-channel 量化；
- 缩放因子与零点的选择；
- 量化误差传播与激活分布对结果的影响。

---

## 3. 工具链与格式
- llama.cpp + GGUF：适用于本地快速推理；
- ONNX + onnxruntime：跨平台推理与加速；
- GPTQ / bitsandbytes：训练后量化与低比特支持。

---

## 4. Worked Example：简单量化与误差估计
示例实验：取小模型权重，选择一个标量量化方案，把浮点张量量化为 INT8，计算量化前后模型在小数据集上的 perplexity 与 latency，对比并讨论误差来源。

---

## 5. 练习（Exercises）
1. 使用现成工具对小模型做 INT8 与 INT4 的训练后量化，记录并比较性能指标。
2. 解释 per-channel 量化在某些层表现更好的原因，并给出一个简单的数学说明。
3. 设计一个校准集并说明如何评估校准集是否足够代表真实分布。
4. 实现一个脚本自动收集量化前后的 latency/throughput 并输出对比报告。
