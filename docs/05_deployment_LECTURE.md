# 第5章 部署与服务化（Ollama / One-API / 容器化）

## 学习目标
1. 理解本地部署与云部署的权衡；
2. 掌握 Ollama、One-API 等本地/统一管理平台的基本使用场景与配置要点；
3. 能把微调/量化后的模型部署为 API 服务并进行基础监控。

---

## 1. 引言
将模型从实验环境推向生产需要考虑可靠性、可扩展性与成本。本章介绍常见的部署方案，优劣比较，以及在课堂中的可行实践路径（如何在有限资源下完成演示部署）。

---

## 2. 部署策略对比
- 本地单机部署（低延迟、本地数据），适合隐私敏感场景；
- 容器化 + 编排（Docker/Kubernetes）：适合水平扩展与生产化；
- 平台/网关（One-API）：统一管理多个模型、权限与流量路由；

---

## 3. Ollama 快速入门要点
- Modelfile 概念与配置示例；
- 模型导入流程（量化模型导入到 Ollama）；
- 常见参数与资源隔离策略；

---

## 4. 监控、日志与成本控制
- 监控指标：latency、qps、显存/CPU 使用、错误率；
- 日志策略：请求/响应示例、出错样本、采样日志以避免过量储存；
- 成本控制思路：批处理、请求并发限制、模型切分策略

---

## 5. 练习（Exercises）
1. 使用 Docker 将一个量化后的模型封装成容器并运行本地 API；
2. 配置一个简单的 Prometheus 导出（或使用 psutil 脚本）采集模型容器的基本指标；
3. 设计一个简单的流量策略：当请求 qps 超过阈值时如何退化服务（降级策略）。
