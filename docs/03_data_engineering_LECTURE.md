# 第3章 数据工程：数据收集、清洗与质量控制

## 学习目标
1. 理解高质量数据对微调与评估的关键性；
2. 掌握数据清洗、去重、格式化与标注常用方法；
3. 能设计一套数据质量检查流程并实现自动化校验（包括质量指标与采样策略）；
4. 了解数据合成与脱敏的常用技术与风险。

---

## 1. 引言
数据是模型效果的核心。对于工程实践型课程，我们不仅要教学员如何使用现成数据集，还要教会他们如何评估、清洗与增强数据，以获得稳定且可靠的微调效果。本章强调可操作的方法和自动化工具链。

---

## 2. 数据收集与许可
- 来源：公开语料、内部数据、合成数据、众包标注
- 合规：版权、隐私、个人信息保护（PII）与使用许可（CC、专有）
- 采样：随机采样 vs 分层采样（按类/领域/时间分布）

---

## 3. 数据清洗常用步骤
1. 标准化编码（UTF-8）、统一换行符与空白处理；
2. 去重：文本去重（hash+近似重复检测）；
3. 噪声过滤：去除过短/过长、非目标语言或含敏感信息的记录；
4. 格式化为训练所需格式（instruction-following、pair、jsonl）；
5. 质量打分：人工抽样标注 + 自动质量指标（语言模型 perplexity、length distribution、toxicity 检测）。

---

## 4. 数据质量指标示例
- 覆盖度（vocabulary coverage）
- 重复率（exact & fuzzy）
- 平均长度与长度分布
- 语义多样性（embedding-based cluster counts）
- 语法/拼写错误率（基于语言工具）

---

## 5. 自动化与工具链
- 使用脚本（python）批量处理与校验（示例：dedupe.py, quality_check.py）
- Embedding-based sampling：用小型 embedding 模型计算向量，再做聚类/采样以提升多样性
- 标注流程：label-studio / prodigy / 简单 CSV+review 流程

---

## 6. 练习（Exercises）
1. 对给定的 1k 条样本，写脚本计算并报告重复率、平均长度与 top-50 词频。
2. 设计一个简单的近似去重（MinHash 或 Locality Sensitive Hashing）流程并在样本上验证效果。
3. 给出三种数据脱敏方案并比较优缺点（实现成本、残留风险）。
4. （高级）用 embedding 聚类方法抽样构建小规模高质量训练集，并给出选择策略说明。
