# 第3章 数据工程（教科书式）

## 学习目标
完成本章后，你应能：
1. 解释训练数据质量对微调效果的影响与常见衡量指标；
2. 用自动化脚本完成基本的清洗、去重与格式化流程；
3. 设计并实现简单的质量检测流水线（重复率、长度分布、语义多样性）；
4. 了解脱敏方法及其在工程中的权衡。

---

## 1. 引言与动机
在 LLM 工程中，数据质量往往比模型架构本身对最终效果更关键。本章通过工程视角讲解如何把“脏数据”变成可用数据，并引导你建立可复用的数据流水线。

---

## 2. 数据收集与合规
收集渠道：公开语料、内部日志、爬取、众包标注与合成数据。
重要点：数据许可（版权）、隐私（PII）、数据留存政策。工程实践中必须在收集前确认合规性，并在元数据中记录来源与许可信息。

---

## 3. 清洗与去重（实用步骤）
1. 统一编码与文本规范化（去除不可见字符、统一空格）；
2. 精确去重（hash）与近似去重（MinHash/LSH）；
3. 过滤异常长度与语言检测；
4. 格式化成训练格式（jsonl: {"prompt":..., "response":...}）。

工具提示：用 python 的 fasttext/langdetect 做语言检测；用 datasketch / datasketch-minhash 做近似去重。

---

## 4. 数据质量度量（常用指标）
- 重复率
- 平均长度与长度分布
- 词汇覆盖度
- 语义多样性（embedding 聚类数）
- 质量估分（人工抽检比率）

---

## 6. 练习（Exercises）
1. 实现一个脚本统计给定语料的重复率、平均长度与词频分布。
2. 在样本数据上实现 MinHash 去重并比较与精确去重的效果（时间/空间对比）。
3. 设计一个简单的 embedding 聚类抽样流程并提交抽样结果说明策略。
4. 列举三种脱敏策略并讨论其优缺点（实现复杂度、残留风险）。
